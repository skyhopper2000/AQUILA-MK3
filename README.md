This is the repository for two tools developed for personal use with AMEC-style Bible Quizzing. AQUILA is a desktop app to which a user can upload questions and can quiz themselves on those questions via a TTS engine and a built-in-buzzer system. PRISCILLA is a local generative AI model which generates questions in the style of AMEC quizzing questions. AQUILA will be provided here under MIT license, access to PRISCILLA may be restricted.
